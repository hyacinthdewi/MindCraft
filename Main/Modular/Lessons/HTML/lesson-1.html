HTML Structure

Lesson 1 • What each part does
Clear step-by-step:
  1. Doctype — tells the browser this is an HTML file: <!DOCTYPE html>.
  2. <html> — the root element that wraps the whole page.
  3. <head> — invisible information the browser uses (title, meta, links).
  4. <body> — everything the user sees on the page (text, images, buttons).
Short tip: the head is for the browser; the body is for the person using the page. 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My First Webpage</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>This is my first page. Welcome!</p>
  </body>
</html>
Result (how the browser shows the body):

Hello World!

This is my first page. Welcome!

Head & Body

Lesson 2 • Invisible vs visible
Quick and friendly:
  • Head holds the page title (shows in browser tab), links to styles, and useful metadata.
  • Body holds headings, paragraphs, images — everything a person sees.
Example: changing the title does not change the page text — it changes the browser tab. 
<html>
  <head>
    <title>My Webpage</title> <!-- shows in the browser tab -->
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Welcome!</h1>
    <p>This shows up on the page.</p>
  </body>
</html>

Browser result:

Welcome!

This shows up on the page.

Tags & Nesting

Lesson 3 • Structure rules
Important rules for tags:
  • Most tags have an opening and a closing form: <tag> ... </tag>.
  • When one tag is inside another, they must close in the reverse order (last opened, first closed).
<div>
  <p>This is <strong>nested</strong> text.</p>
</div>

This is nested text.

Your Challenge

Lesson 4 • Practice
Try this small task:
  1. Set the page title to your name.
  2. Inside the body add an <h1> with a greeting and a <p> with a short intro.
Replace the placeholders with your real name — then open the file in a browser to see the tab title and the page content. 
<!DOCTYPE html>
<html>
  <head>
    <title>Your Name Here</title>
  </head>
  <body>
    <h1>Hello — I'm Your Name!</h1>
    <p>A short sentence about me.</p>
  </body>
</html>

When you're done, save as index.html and open in a browser to check the title and the page content.

Hello — I'm Your Name!

A short sentence about me.
